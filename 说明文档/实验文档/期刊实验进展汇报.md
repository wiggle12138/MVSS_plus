## 3. 已完成实验：配置与结果

### 3.1 Exp6：DeltaAggregateWindowMs 窗口敏感性

**目的**：扫描出站 delta 聚合窗口对 sync 开销、Stage3 时延与正确性的影响；为 Exp2 选定固定窗口。

**统一控制量**

| 参数 | 取值 |
|------|------|
| 策略 | MVSS-Delta |
| 数据集 | `selectedTxs_300K.csv` |
| MaxInjectTxs | 24000 |
| SyncProbeMaxAccounts | 50 |
| EnableSyncProbe | true |
| Block_interval / MaxBlockSize | 2 s / 500 |
| 窗口 W (ms) | 0, 50, 100, 200, 500 |
| 每组 run 数 | 3 |

**已跑规模**

| 规模 | 目录 |
|------|------|
| 2 分片 × 2 节点 | `results/exp6_sensitivity/raw/shards2_nodes2/window_{W}/run{K}/` |
| 4 分片 × 4 节点 | `results/exp6_scale_4x4_full/raw/shards4_nodes4/window_{W}/run{K}/` |

**主要结论**

- **全局性能**：各窗口 `tps_global`、`latency_p95` 波动 **<0.1%**，窗口不拖累整体吞吐/时延。
- **Stage3**：4×4 下 `sync_send_count`、batch 规模跨窗口基本不变；`stage3_ms` 随 W 增大略降（约 400 ms 量级），差异有限。
- **正确性**：2×2 全窗口 `probe_ok=100%`；4×4 下 **W=0 仅 33%**，**W≥50 均为 100%**。
- **Exp2 固定窗口**：**200 ms**（正确性稳定，Stage3 优于 W=0，flush 等待少于 500 ms）。

**原始指标对比（各窗口，3 run 均值）**

> 数据来源：`results/exp6_sensitivity/metrics_recalc_v2/`（对 raw CSV 调用 `metrics_definitions.py` 重算，未重跑仿真）。  
> 统一条件：MVSS-Delta，probe=50，inject=24000。

### 3.2 Exp2：高并发迁移压力（MVSS vs MVSS-Delta）

**目的**：多账户同时迁移时，增量 sync（Delta）相对全量 sync（MVSS）的带宽与消息开销差异。

**正式对照配置（probe=50）**

| 参数 | MVSS | MVSS-Delta |
|------|------|------------|
| 规模 | 4×4 | 4×4（同左） |
| MaxInjectTxs | 24000 | 24000 |
| SyncProbeMaxAccounts | 50 | 50 |
| DeltaAggregateWindowMs | 0（策略不用窗口） | **200**（Exp6 收敛值） |
| run 数 | 3（新跑） | 3（**复用 Exp6**） |
| EnableSyncProbe | true | true |

**数据来源**

| 策略 | 原始数据路径 |
|------|----------------|
| MVSS | `results/exp2_concurrency/raw/probe_50/strategy_MVSS/shards4_nodes4/window_0/run{1,2,3}/` |
| MVSS-Delta | `results/exp6_scale_4x4_full/raw/shards4_nodes4/window_200/run{1,2,3}/` |

**主要结论（3 run 均值±std）**

| 类别 | MVSS | MVSS-Delta |
|------|------|------------|
| tps_global | 306.9±0.05 | 306.9±0.03 |
| tps_migration | 354.0±0.41 | 353.7±0.45 |
| latency_p95 (ms) | 9784±5 | 9791±6 |
| sync_send_count | 100 | **3** |
| sync_bandwidth_mb | 0.193±0.0003 | **0.012** |
| exp6_stage3_makespan_ms | 4076±2 | **3877±3** |
| probe_ok | 3/3 | 3/3 |
| rdt_ratio | 0 | 0 |

**解读**

- **假设成立**：Delta 的 sync 次数与带宽显著低于 MVSS（带宽约 **16×**），Stage3 约快 **200 ms**。
- **全局指标不能区分策略**：TPS/时延差异 <0.02%，Exp2 论文表述应主读 **sync 开销 + Stage3**，全局指标作「无退化」旁证。
- **探针 50 未触发异常**：实际探针数 = min(50, len(newAddrs))，本轮迁出账户充足，日志为「本轮迁出探针账户数=50」。

**汇总数据位置**

| 类型 | 路径 | 格式 |
|------|------|------|
| 汇总表 | `results/exp2_concurrency/summary/exp2_probe50_metrics.md` | Markdown |
| 汇总 CSV | `results/exp2_concurrency/summary/exp2_probe50_metrics.csv` | CSV |
| 单 run JSON | `results/exp2_concurrency/metrics/MVSS_probe50_run{K}.json`、`MVSSDelta_probe50_run{K}.json` | JSON |
| 归档副本 | `results/raw_pool/shards4_nodes4/strategy_*/.../` | 与 raw 同结构 |
| 实验设计文档 | `说明文档/实验文档/exp2_高并发迁移压力实验.md` | — |

**驱动脚本**

- MVSS：`run_exp2.bat`（`OUT_ROOT=results/exp2_concurrency/raw/probe_50/strategy_MVSS` 由脚本内置）
- 汇总：`python scripts/summarize_exp2_metrics.py --probe 50`

**遗留/非正式数据**

- `results/exp2_concurrency/raw/probe_3/`：probe=3 冒烟，参数偏小，**不用于正式结论**。

### 5.1 推荐目录结构

```text
results/
  exp6_sensitivity/          # Exp6 原始 + 2×2
  exp6_scale_4x4_full/       # Exp6 4×4 扩展
```

## 7. 向老师汇报时可强调的结论

1. **工程链路已打通**：探针注入 → 迁移触发 → sync 闭环 → CSV 落盘 → Python 指标 → 汇总表，Exp6/Exp2 均走通。
2. **Exp6 已收口**：窗口对全局 TPS/时延几乎无影响；4×4 下选定 **W=200 ms** 作为 Delta 默认窗口。
3. **Exp2 核心发现（probe=50, 4×4）**：MVSS-Delta 相对 MVSS，sync 带宽约降 **16×**，Stage3 约快 **200 ms**，正确性 100%；全局 TPS/时延无显著差异。
4. **指标分层**：主实验（关探针）与 Stage3 微基准（开探针）分工明确；Exp2/Exp6 属于后者，不宜单独用 `tps_global` 证明 Delta 整体优势。
5. **下一步**：Exp1 四策略扩展；Exp2 probe 阶梯（20）；Exp4 XBlock；Exp3/Exp5 设施开发。
